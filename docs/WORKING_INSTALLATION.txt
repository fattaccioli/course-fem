================================================================================
WHAT WENT WRONG
================================================================================

The problem:
  pip install fenics-dolfinx
  # Error: No matching distribution

Why:
  - "fenics-dolfinx" is not the correct package name on PyPI
  - The correct package is "fenicsx"
  - OR use "fenics" from conda-forge

The fix:
  Use: pip install fenicsx
  OR use: conda install -c conda-forge fenics
